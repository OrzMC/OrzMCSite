Paper 与 Folia 双核心插件全景对比

2026-08-19

信息截至 2026-08-19。插件版本/渠道可能随时间变化，本文聚焦核心差异与插件对应关系，版本号仅作参考。

1. 核心服务端对比🔗

维度🟢 Paper🟣 Folia
定位稳定全功能，插件生态最全分区线程并行，性能上限更高
下载渠道papermc.io/downloads/paperpapermc.io/downloads/folia
版本状态STABLE 稳定版BETA（26.1.2 才是 STABLE，节奏比 Paper 慢）
线程模型单主线程（全局串行）分区线程（region 级并行）
命令方块✅ 正常❌ 架构性禁用（24 个命令连带被禁，含 /function /scoreboard /tag 等）
插件兼容全生态支持需 folia-supported: true 标记，否则拒载；标记 ≠ 真兼容
Java 要求26.x 需 Java 25同左
回退能力—回退 Paper = 100% 恢复（插件矩阵反向回退）

3. 检索 Folia 插件的正确姿势🔗

  • 用 Modrinth loaders 含 folia 过滤： 检索示例
  • ❌ Hangar API 不能查 Folia：supportedPlatforms 只标 PAPER（WorldEdit 支持 Folia 也只显示 PAPER），不可用作 Folia 检索依据
  • ⚠️ folia-supported: true 标记 ≠ 真兼容：PaperMC 官方明示「声明标记不足以保证支持」，WorldGuard 官方承认 experimental

4. 一句话总结🔗

Paper = 稳定全功能（命令方块/插件生态全支持）；Folia = 分区线程性能更强，但命令方块被禁 + 9 个插件需平替（均已落地）。 两者共享同一世界文件时绝不可同时启动；Folia 若需回退，反向执行平替矩阵即可 100% 恢复。
