Minecraft Java 版需要启动器才能运行。本页帮你选一个合适的启动器；安装、登录与使用细节请以各启动器**官方页面**为准。想申请白名单、查服务器地址，见[玩家手册](/user/)。

## 选择启动器

| 使用场景 | 推荐 | 下载 / 官方页面 |
|:--|:--|:--|
| Windows / macOS / Linux 通用 | **OrzMC 命令行启动器** | [官方页面](https://orzmc.github.io/OrzPythonMC/) · [下载](https://github.com/OrzMC/OrzPythonMC/releases) |
| 只用 macOS，想要图形界面 | **OrzMC macOS 启动器** | [下载](https://github.com/OrzMC/OrzMCApp/releases) |
| 想要图形界面和更丰富的管理功能 | **HMCL**（第三方） | [官网](https://hmcl.huangyuhui.net/) |

## OrzMC 命令行启动器

跨平台的启动工具：一条命令安装，自动下载所需 Java，版本任选，支持原版与 Fabric / Forge 模组。安装与使用说明见官方页面：[**OrzPythonMC**](https://orzmc.github.io/OrzPythonMC/)

## OrzMC macOS 启动器

macOS 原生应用，图形界面操作，适合只用 macOS 的玩家。下载安装见：[**OrzMCApp 下载**](https://github.com/OrzMC/OrzMCApp/releases)

## HMCL（第三方备选）

老牌的跨平台第三方启动器，图形界面、中文友好，支持版本管理、模组安装与多实例。下载与使用教程见 [HMCL 官网](https://hmcl.huangyuhui.net/)。
