浏览器直接运行完整 Java 版目前没有官方方案。下面按“官方程度 / 版本覆盖 / 合规风险”对比常见的 WebMC 方案。

| 方案 | 类型 | 版本支持 | 核心限制 | 适合场景 |
|---|---|---|---|---|
| [Minecraft Classic](https://classic.minecraft.net/) | Mojang 官方 | Classic 经典版 | 仅支持方块放置，功能基础 | 快速体验、活动页、了解网页版边界 |
| [Eaglercraft](https://eaglercraft.com/) | 第三方社区 | 可运行接近 Java 版的功能 | 反编译并重新打包原 Java 客户端代码，违反 Mojang EULA，合规风险高；不建议正式开服使用 | 只用于研究浏览器端实现思路，不对外分发 |
| [mcjs](https://www.mc.js.cool/) | 中文社区 | `1.8.8` / `1.12` | 完成度较高但版本较老，长期维护状态不明 | 测试老版本体验，不适合新版本服务器 |

## 选型建议

1. 只是想快速试玩，优先使用官方 [Minecraft Classic](https://classic.minecraft.net/)。
2. 需要正式联机，优先使用 Java 版官方客户端，或用 GeyserMC 等合规通道接入基岩版玩家。
3. 第三方 WebMC 适合做技术验证，不应作为社区主推入口；引用或推荐前要确认当前维护状态和许可证。

如果未来出现由 Mojang 官方支持、或完全基于官方协议的 Web 客户端实现，再更新本页作为正式替代方案。
