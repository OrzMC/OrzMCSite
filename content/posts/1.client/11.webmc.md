想在浏览器里直接玩 Minecraft，现在可行：社区项目 **Eaglercraft** 把 Java 版客户端编译到浏览器里，跑的还是原版协议，所以能连真实的 Java 服务器——前提是服务器做了对应适配。

本页面向两类人：**玩家**（怎么进服）和**服主**（要开什么，浏览器玩家才能进来）。

## 玩家：三步进服

1. 打开 [Web 客户端](https://eaglercraft.com/play?version=26.3)（新标签打开，无需安装；首次要下载几十 MB，等一下）。
2. 进入游戏后：**多人游戏 → 直连（Direct Connection）**，粘贴服务器卡片上的 **Web客户端连接地址**（`wss://` 开头）。卡片上的「在浏览器中玩」按钮会自动复制这个地址。
3. 进服先 `/register 密码 重复密码` 注册，之后每次 `/login 密码`。账号与 Java 版共用：**同名就是同一个玩家**（背包、位置、权限都在一起）。

> 浏览器玩家同样要走白名单：不在名单里会被拒绝，先在玩家群申请，见[玩家手册](/user/)。

### 卡顿或掉线怎么办

- 确认浏览器**硬件加速**已开（Chromium 系可在 `chrome://gpu` 看 Hardware accelerated），只留一个游戏标签
- 游戏标签**保持在前台**，别锁屏或休眠；优先有线 / 5 GHz Wi-Fi
- 仍卡就降低游戏内视野（渲染距离）

> 浏览器端对设备很敏感：同一台机器、同一个服，硬件加速能连十几分钟不掉，纯软件渲染可能几分钟就断。**先查客户端环境，再怀疑服务器。**

## 服主：接入前要准备的四件事

1. **选形态**：单服用插件直挂（EaglerXPaper，装完即开 WSS 入口，但不能改玩家 UUID、不支持 Folia）；多服 / 大厅 / Folia 走代理（Velocity + EaglerXServer，能统一身份）。
2. **整链离线模式**：桥接层只支持离线登录，代理和后端都要 `online-mode=false`。浏览器玩家一律是离线 UUID，**同名 = 同账号**，所以白名单和口令是唯一的门。
3. **给一个 `wss://` 入口**：浏览器只认 TLS。用已有的反向代理终结证书（建议单独一个子域），透传 WebSocket 的 `Upgrade`、关掉缓冲，并把真实 IP 头传给桥接层（缺了会被拒连）。
4. **补齐身份措施**：白名单收紧 + 登录插件强制口令；上线前确认所有 op / 权限名字都已注册（权限按 UUID 授权，而 UUID 由名字派生）；与基岩端共存时给基岩组单独放行反作弊，浏览器端一般不需要。

> 端口、拓扑与验收细节见 [`deploy/docs/eaglercraft-deploy.md`](https://github.com/OrzMC/OrzMCDeploy/blob/main/docs/eaglercraft-deploy.md)。

## 现在能选哪些 Web 客户端

| 入口 | 版本 | 适合 |
|:--|:--|:--|
| [Minecraft Classic](https://classic.minecraft.net/)（官方） | 2009 经典版 | 快速试玩；只有创造、不能联机、需要键盘 |
| [Eaglercraft 官方站](https://eaglercraft.com/) | 26.3（最新）、26.2、1.8.8、1.12.2 等 | 联机首选；带账号云存档、服务器目录、共享世界 |
| [MCJS 中文站](https://www.mc.js.cool/) | 1.5.2 ～ 26.3（含整合包） | 中文汉化、多版本一站式、自带联机中继 |

版本要和服端桥接支持的协议对齐：服务端是 26.3 就用 26.3 客户端，老服（1.8 / 1.12）用对应版本。

## 一句话合规提醒

Eaglercraft 是把 Java 客户端反编译后重新编译到浏览器的第三方项目，**不符合 Mojang EULA**。我们只提供连接方式，不在本站分发客户端本体；是否对外推广请自行评估。
