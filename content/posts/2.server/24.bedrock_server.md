## 服务端部署

本文以 Linux 为例。请从官网下载**当前版本**，不要继续使用示例中的旧版本号；下载后校验官方给出的 SHA-256。

[基岩版服务端下载](https://www.minecraft.net/en-us/download/server/bedrock)

### 1. 准备目录与用户

```bash
sudo useradd -r -m -d /opt/bedrock minecraft
sudo mkdir -p /opt/bedrock
sudo chown -R minecraft:minecraft /opt/bedrock
```

不建议用 root 长时间运行游戏服务端；程序、存档、备份目录尽量分离。

### 2. 下载并解压

将下载文件放到 `/tmp` 后解压到 `/opt/bedrock`，再按官方页面给出的 SHA-256 校验文件完整性：

```bash
cd /tmp
sha256sum bedrock-server-*.zip
unzip bedrock-server-*.zip -d /opt/bedrock
cd /opt/bedrock
```

### 3. 首次启动

```bash
sudo -u minecraft env LD_LIBRARY_PATH=. ./bedrock_server
```

首次启动会生成或读取 `server.properties`、`allowlist.json`、`permissions.json`、`worlds/` 等文件。建议先启动一次确认目录结构，再停止服务修改配置。

Ubuntu 下查看端口打开情况：

```bash
sudo lsof -i :19132
```

### 4. 常用配置

编辑 `server.properties`，常用项如下：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `server-port=19132` | `19132` | IPv4 游戏端口，UDP |
| `server-portv6=19133` | `19133` | IPv6 游戏端口，UDP |
| `online-mode=true` | `true` | 开启 Xbox 在线认证，不建议关闭 |
| `allow-list=false` | `false` | 是否启用 `allowlist.json` 白名单 |
| `max-players=10` | `10` | 最大在线人数 |
| `gamemode=survival` | `survival` | 默认游戏模式 |
| `difficulty=easy` | `easy` | 难度 |
| `allow-cheats=false` | `false` | 是否允许作弊与命令 |
| `view-distance=32` | `32` | 客户端视距 |

如果启用白名单，把玩家 XUID 加入 `allowlist.json`，并把 `allow-list=true`。

### 5. 防火墙

基岩版使用 UDP 协议，云服务器安全组和系统防火墙都要放行：

```bash
sudo ufw allow 19132/udp
sudo ufw allow 19133/udp
```

### 6. 使用 systemd 托管

将以下内容保存为 `/etc/systemd/system/bedrock.service`，按实际路径调整：

```ini
[Unit]
Description=Minecraft Bedrock Server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=minecraft
Group=minecraft
WorkingDirectory=/opt/bedrock
ExecStart=/opt/bedrock/bedrock_server
Environment=LD_LIBRARY_PATH=/opt/bedrock
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now bedrock
sudo systemctl status bedrock
```

### 7. 备份

基岩版存档位于 `worlds/`。生产环境可先执行 `save hold`，确认 `save query` 完成后再复制目录，最后执行 `save resume`；最简单稳妥的方式是停止服务后备份。

## 基岩版客户端国际版下载

官方渠道：iOS 使用国际区 App Store，Android 使用 Google Play，Windows 使用 Microsoft Store。

中国大陆无官方商店入口时的常见路径：

- 申请美区 `Apple ID`
- 通过合规渠道购买 Minecraft 兑换码
- 登录美区 `Apple ID`，使用兑换码安装国际版 Minecraft

第三方商店、代充和共享账号存在封号与交易风险，安装后应尽快改为本人账号验证。

基岩版客户端接入 Java 版服务器可使用 GeyserMC，详见 [服务端插件](/posts/2.server/22.paper_server_plugins/)。
