## 1. 迁移到 Paper

- 从 Vanilla 迁移：地图保持单目录嵌套维度结构（`world/dimensions/minecraft/{overworld,the_nether,the_end}/`），无需拆分。
- 从 Spigot 迁移：旧版三目录结构（`world/` + `world_nether/` + `world_the_end/`）会在 Paper 26.1 首次启动时自动迁移为单目录嵌套结构，替换 JAR 文件即可，不需要手动拆分。
- 迁移细节、目录变化与清理建议见 [Paper 26.1 世界目录结构迁移报告](/posts/3.other/33.world-directory-migration-report/)。

## 2. 升级服务端前检查

升级前先完整备份，再对照以下文件确认配置是否会被覆盖：

```
.
├── eula.txt            // eula协议文件，需要同意，否则无法启动
├── plugins             // 服务器安装的插件所在目录，主要关注插件配置文件
├── server-icon.png     // 服务器自定义图标
├── server.properties   // 服务器配置属性，离线/在线模式
└── world               // 服务器世界存档（单目录嵌套维度：world/dimensions/minecraft/{overworld,the_nether,the_end}）
```

> 对外开服前，请对照 [对外开服安全清单](/posts/2.server/26.papermc-open-server-checklist/) 逐项落实安全加固。

## 3. 常用配置与安全

### 粘性活塞复制特性

```ini
allow_piston_duplication=true
```

### 防止 X-Ray 透视挖矿

开启 PaperMC 服务端内置 Anti-XRay：

```yaml
# config/paper-world-defaults.yml
anti-xray:
  enabled: true       # 开启反透视功能
  engine-mode: 2      # 强烈推荐
  max-block-height: 64
  update-radius: 2
  lava-obscures: true # 开启岩浆防透视
  use-permission: false
```

### 维护操作纪律

服务器维护禁止使用 `rm -rf` 删除文件，误删无法恢复，风险很高，已有惨痛教训。需要删除时先移动到备份目录，确认服务正常后再清理。

## 4. 常用指令速查

### 重设世界出生点

```bash
/gamerule spawnRadius 0
/setworldspawn x y z
```

### 反向隧道示例

Linux 服务器需要临时把本机端口反向暴露给外网主机时，可参考以下命令，并按实际主机和端口调整：

```bash
ssh -NfR 8010:localhost:22 joker@jokerhub.cn
```

该命令只应作为临时管理通道，不应替代防火墙和密钥认证。

### WorldEdit + WorldGuard 保护领域

- 获取选择区域的木斧: `//wand`
- 选中刚才获得的木斧，选择立方体区域对角线一个顶点，点击左键
- 选择立方体区域对角线另一个顶点，点击左键
- 扩展选中的区域最底部从基岩一直到天空最高处的立方体区域： `//expand vert`
- 命名刚才选中的区域，这样就创建了一个区域: `/rg claim <region name>`
- 为区域设置标记，指定区域内允许什么、不允许什么: `/rg flags <region name>`
- 为区域添加成员: `/rg addmember <region name> <user or user group name>`
- 为区域添加所有人: `/rg addowner <region name> <user name>`
- 查看区域信息: `/rg info <region name>`
- 设置子区域: `/rg setparent <child region name> <parent region name>`
- 区域可以嵌套
- 可以跨存档导出导入区域：`//copy` 保存到剪贴板 → `/schem save <filename>` 存盘 → 其它存档 `/schem load <filename>` 导入 → `//paste` 粘贴到当前位置
- 清空玩家自己的所有物品：`/clear <player name>`

## 5. 排障与日志

### 查看指定日期记录服务器的玩家

```bash
zcat 2021-07-31-1.log.gz | grep logged | cut -d ' ' -f 4 | cut -d '[' -f 1 | sort | uniq
```

### ViaVersion 限流报错

```text
lost connection: You are sending too many packets, :(
```

解决办法：修改 ViaVersion 插件的 `config.yml`：

```yaml
max-pps: -1
tracking-period: -1
```
