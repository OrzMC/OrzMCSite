## 安装插件

- 插件下载渠道：[Bukkit Plugins](https://dev.bukkit.org/bukkit-plugins) / [Spigot](https://www.spigotmc.org/) / [Hangar](https://hangar.papermc.io/) / [Modrinth](https://modrinth.com/plugins)
- 插件使用说明：[插件使用百科](https://mineplugin.org/)

安装流程：

1. 只从官方或可信渠道下载插件 JAR。
2. 把 JAR 放入服务端 `plugins/` 目录。
3. **重启服务端**，不要使用 `/reload`。
4. 查看 `logs/latest.log` 是否成功加载，再按插件文档配置。

插件存在依赖时，必须先安装依赖插件，例如 Vault、PlaceholderAPI、CMILib、ViaVersion、KotlinLoader。

## 插件相关问题

### EssentialsX

Essentials 会覆盖部分原版指令，导致命令方块无法识别目标选择器 `@a @e @r @s @p`。解决办法是在 `commands.yml` 中设置：

```yaml
command-block-overrides: ['*']
```

让命令方块使用 Mojang 原始指令，而不是 Essentials 覆盖过的指令。

### WorldEdit

WorldEdit 配置中有符号链接选项，开启后可以让区域保存到磁盘的功能生效。

### LoginSecurity

#### OP 权限指令

使用 `/lac` 移除密码并重新载入游戏。

#### 一般用户指令

使用 `/register <password>` 注册用户密码

使用 `/changepass <old> <new>` 变更用户密码

使用 `/login <password>` 登录

使用 `/logout` 登出

### SkinsRestorerX + SkinSystem 定制角色皮肤

> 以下为历史部署记录：SkinSystem 旧脚本基于 PHP 7.2，新服优先查看 [SkinsRestorer 当前文档](https://github.com/SkinsRestorer/SkinsRestorer/wiki)。

旧方案安装 SkinSystem 时，用 `sudo` 执行安装脚本，安装必要软件并配置 MySQL 数据库。之后把 Nginx 配置放入 `/etc/nginx/conf.d/`，并将 `fastcgi_pass unix:/run/php/php7.2-fpm.sock;` 替换为当前 PHP-FPM 的 `listen` 路径，重启 Nginx 并访问 `8001` 端口。

如果皮肤上传界面提示 `504`，可尝试重启 PHP-FPM：

```bash
sudo systemctl restart php7.2-fpm.service
```

#### 将 MySQL 中的皮肤数据迁移到另一台服务器

使用 `mysqldump` 导出再导入即可。
