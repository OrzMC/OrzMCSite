## 1. 核心服务端对比

| 维度 | 🟢 Paper | 🟣 Folia |
|:--|:--|:--|
| **定位** | 稳定全功能，插件生态最全 | 分区线程并行，性能上限更高 |
| **下载渠道** | [papermc.io/downloads/paper](https://papermc.io/downloads/paper) | [papermc.io/downloads/folia](https://papermc.io/downloads/folia) |
| **版本状态** | STABLE 稳定版 | BETA（26.1.2 才是 STABLE，节奏比 Paper 慢） |
| **线程模型** | 单主线程（全局串行） | **分区线程**（region 级并行） |
| **命令方块** | ✅ 正常 | ❌ **架构性禁用**（24 个命令连带被禁，含 /function /scoreboard /tag 等） |
| **插件兼容** | 全生态支持 | 需 `folia-supported: true` 标记，否则拒载；标记 ≠ 真兼容 |
| **Java 要求** | 26.x 需 Java 25 | 同左 |
| **回退能力** | — | 回退 Paper = 100% 恢复（插件矩阵反向回退） |

## 2. 插件全景对照（对应关系 + 渠道 + 功能）

> 插件选型与开发相关文章：[服务端插件](/posts/2.server/22.paper_server_plugins/)、[PaperMC插件开发](/posts/2.server/23.papermc_plugin_dev/)。

### 2.1 Paper 独有 → Folia 平替

> Folia 不兼容的插件用平替方案替代，功能覆盖 + 数据迁移均已落地。

| Paper 插件 | 功能 | Folia 平替 | 平替渠道 | 平替功能 |
|:--|:--|:--|:--|:--|
| EssentialsX | 基础指令（tpa/home/warp/kit 等） | **EssentialsC** | [Modrinth](https://modrinth.com/plugin/essentialsc) · [GitHub](https://github.com/GodlyCow203/EssentialsC) | 同功能 + 吸收 GetMeHome |
| Vault | 经济/权限 API 桥 | **VaultUnlocked** | [Modrinth](https://modrinth.com/plugin/vaultunlocked) · [GitHub](https://github.com/TheNewEconomy/VaultUnlockedAPI) | drop-in 平替 |
| GriefPrevention | 领地保护 | **GriefPrevention3D** | [SpigotMC](https://www.spigotmc.org/resources/griefprevention-3d-subdivisions-folia-support.127137/) | GP fork + Folia fix + 3D 分区 |
| LoginSecurity | 离线服注册/登录 | **SimpleLogin** | [Modrinth](https://modrinth.com/plugin/simple-login) | 登录 + BCrypt + 可选 2FA |
| DeathChest | 死亡箱 | **AxGraves** | [Modrinth](https://modrinth.com/plugin/axgraves) · [GitHub](https://github.com/Artillex-Studios/AxGraves) | 死亡箱 + 回死亡点 |
| BackOnDeath | 回死亡点 | ↑ 并入 AxGraves | — | `/axgraves tp` |
| GetMeHome | /home 多 home | ↑ 并入 EssentialsC | — | 自带多 home |
| CustomWorldHeight | 世界高度 1088 | ❌ 已移除（两端） | — | 世界回 384 生态 |

## 3. 检索 Folia 插件的正确姿势

- **用 Modrinth `loaders` 含 `folia` 过滤**：[检索示例](https://modrinth.com/plugins?q=&g=1.21&l=folia)
- ❌ **Hangar API 不能查 Folia**：`supportedPlatforms` 只标 PAPER（WorldEdit 支持 Folia 也只显示 PAPER），不可用作 Folia 检索依据
- ⚠️ **`folia-supported: true` 标记 ≠ 真兼容**：PaperMC 官方明示「声明标记不足以保证支持」，WorldGuard 官方承认 experimental

---

## 4. 一句话总结

> **Paper** = 稳定全功能（命令方块/插件生态全支持）；**Folia** = 分区线程性能更强，但**命令方块被禁** + 9 个插件需平替（均已落地）。
> 两者共享同一世界文件时**绝不可同时启动**；Folia 若需回退，反向执行平替矩阵即可 100% 恢复。
