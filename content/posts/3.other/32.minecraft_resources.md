以下链接按用途分类。第三方站点的可用性和维护状态会随时间变化，公开引用前建议先核对。

## 官方与核心下载

| 资源 | 用途 | 注意点 |
|---|---|---|
| [Paper](https://papermc.io) | Paper/Folia 核心下载与文档入口 | 生产环境从官方下载，校验版本 |
| [SpigotMC](https://www.spigotmc.org/) | 插件与资源发布站 | 注意插件更新时间和兼容版本 |
| [Bukkit](https://bukkit.org) | Bukkit 插件生态历史入口 | 老项目较多，优先看维护状态 |
| [Sponge](https://www.spongepowered.org) | Sponge 服务端与 API | 面向 Sponge 开发/开服 |
| [Minecraft Forge](https://files.minecraftforge.net) | Forge 模组加载器 | 下载前确认 MC 版本 |
| [Modrinth](https://modrinth.com/mods) | 模组/插件资源站 | 新版本资源更新通常更快 |
| [CurseForge](https://www.curseforge.com/minecraft/modpacks) | 整合包与模组资源 | 注意客户端/服务端文件区分 |
| [Minecraft 微软官方](https://www.minecraft.net/zh-hans/) | 官方游戏与账号入口 | 账号安全优先走官方渠道 |
| [Minecraft 网易官方](http://mc.163.com) | 中国版 Minecraft | 与中国版客户端/服务器对应 |

## 协议与运维

| 资源 | 用途 | 注意点 |
|---|---|---|
| [Minecraft 协议百科](https://minecraft.wiki/w/Protocol) | Java 版协议总览 | 服务端/启动器开发必读 |
| [Server List Ping 协议](https://minecraft.wiki/w/Java_Edition_protocol/Server_List_Ping) | 服务器列表状态查询 | 与 MOTD/状态插件相关 |
| [Query 协议](https://minecraft.wiki/w/Query) | UDP 状态查询 | 需要放行 UDP 端口 |
| [RCON 协议](https://minecraft.wiki/w/RCON) | 远程控制协议 | 无加密，绝不暴露公网 |
| [Minecraft 官方 Bug 报告](https://bugs.mojang.com/projects) | 官方问题跟踪 | 搜索已有问题后再提交 |
