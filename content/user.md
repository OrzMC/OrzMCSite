## 欢迎加入 OrzMC

这里是一个由玩家共同建设的 Minecraft 社区。服务器中一些热爱创造的小伙伴花费了大量心力建造出各种漂亮的建筑，希望刚加入的朋友不要随意破坏，**尊重他人的劳动成果**。

如果是完全小白，进服后感觉没有玩伴或者不太熟悉环境，欢迎加入**玩家群**——群里有很多资深玩家可以带你。玩家群入口在下方服务器卡片上，点击即可加入。

---

## 快速进服（3 步）

### 第 1 步：申请白名单

服务器采用**强制白名单**（未在白名单内的玩家无法进入）。请在下方**服务器卡片上点击「玩家群」加入**，向管理员提交你的游戏用户名，审核通过后即可进服。

### 第 2 步：连接服务器

服务器实时状态与地址（点击卡片可查看地址、加入玩家群）：

{{< server-status tags="cn" >}}

1. 启动游戏 → 多人游戏 → 添加服务器，填入上方卡片中的地址
2. 首次进入会要求**注册密码**（防止账号被盗用），在聊天框输入：

```
/register 你的密码 重复密码   ← 首次注册
/login 你的密码               ← 之后每次进入登录
```

3. 登录成功即可开始游戏！

> 💡 **/help LoginSecurity** 可查看登录插件的所有可用指令。

### 第 3 步：开始游戏

进服后输入 `/guide` 查看新手书，输入 `/menu` 打开服务器菜单。下面从常用指令开始认识这个世界～

## 常用指令速查

| 回复 | `/r 内容` | 快速回复上一位私聊你的人 |

| 留言 | `/mail send 玩家名 内容` | 给离线玩家留言，上线即可收到 |

### 💰 经济交易

### 🏠 生存传送

| 指令 | 功能 |
|:--|:--|
| `/sethome` | 在当前站立点设家 |
| `/home` | 传送到家 |
| `/listhomes` | 查看所有的家 |

### ⚰️ 死亡找回

出门探险获得不少物品，可能不小心被苦力怕炸飞，或被小白洞穿。复活后使用 **/back** 可快速回到死亡地点，找回收纳掉落物品的箱子：

- 箱子**五分钟内有效**，超时掉落物品会消失
- 若死于岩浆，箱子会被融化，物品无法找回 **#-_-#**

## 沟通与协作（一起建设生态）

### 游戏内协作

- **互相帮助**：新人缺资源 → 私聊老玩家 `/msg`，或去公共商店买
- **留言联系**：对方不在线 → `/mail send 玩家名 内容`，上线即可收到
- **共同建设**：在群里约好位置 → 一起搭建筑、修路、建传送点

### 群聊机器人（玩家群内直接发送）

| 指令 | 功能 |
|:--|:--|
| `$l` | 查看当前在线玩家 |
| `$w` | 查看白名单列表 |
| `$h` | 查看全部群指令帮助 |
| `$x ?` | 查看单个指令用法示例 |

> 群里还能收到玩家上下线通知，随时知道谁在服里，方便约着一起玩。

### 🏰 保护自己的建筑

| 功能 | 方式 | 等级要求 |
|:--|:--|:--|
| **圈地（GriefPrevention）** | 手持**木锄**左键/右键选两个对角点 → 输入 `/claim 领地名字` | 成员 |
| **区域保护（WorldGuard）** | `//wand` 选区域 → `/rg claim 名字` | 建造者 |
| **玩家商店** | 摆放箱子+告示牌，按提示创建 | 成员 |

> 💡 圈地后你的建筑只有你（和受邀成员）能修改，不怕被熊。**进别人的领地前先打声招呼**，尊重劳动成果。

### 📈 经济生态

> 服务器有经济系统：挖矿、种田、打怪获得资源 → 卖给商店换钱 → 买自己缺的东西。**玩家间自由交易**是生态的重要一环！

## 四级权限成长路径

服务器采用 **访客 → 成员 → 建造者 → 管理员** 四级体系，权限逐级递增，越往上代表你越受信任、能为服务器做的贡献越大。

| 等级 | 身份 | 在线要求 | 核心能力 | 怎么升级 |
|:--|:--|:--|:--|:--|
| 🟢 **L0 访客** | 新朋友 | 进服即有 | 聊天、私聊、看余额、转账、逛商店、回死亡点、领补给 | —— |
| 🔵 **L1 成员** | 活跃玩家 | 在线累计 **10 小时** | 设家/传送、tpa、公共传送点、**圈地保护**、**开玩家商店**、邮件 | **自动晋升**（挂机/游玩均可累积） |
| 🟡 **L2 建造者** | 建设主力 | 表现活跃 | **创造模式**、**飞行**、WorldEdit 快速建造、区域保护、随身工作台 | 向管理员申请（有建设成果/作品更佳） |
| 🔴 **L3 管理员** | 管理团队 | 长期活跃+信任 | 踢人/封禁、白名单管理、传送玩家、发放物品、时间天气、服务器维护 | 管理员邀请/任命 |

### 各等级玩家指南

#### 🟢 访客（L0）— 生存基础体验

**职责**：熟悉服务器、遵守规则、找到自己感兴趣的方向（建筑/红石/农场/贸易）。

**可用指令集**：

| 分类 | 指令 | 功能 |
|:--|:--|:--|
| 聊天 | `/msg 玩家 内容` `/r 内容` `/afk` | 私聊 / 回复 / 挂机 |
| 查询 | `/rules` `/motd` `/list` `/seen 玩家` `/near` | 规则 / 欢迎语 / 在线列表 / 玩家状态 / 附近玩家 |
| 生存 | `/recipe 物品` `/hat` `/depth` `/compass` `/getpos` | 合成配方 / 戴头上 / 深度 / 指南针 / 坐标 |
| 经济 | `/balance` `/baltop` `/pay 玩家 金额` | 余额 / 排行 / 转账 |
| 商店 | `/shop` `/playershops` | 系统商店买卖 / 浏览玩家商店 |
| 死亡 | `/back` | 回死亡点 |
| 其他 | `/skin` `/tpbow` | 自定义皮肤 / 传送弓 |

**✅ 可以做**：完整生存玩法；聊天交友；查询配方/坐标；买卖系统商店物资；逛玩家商店。
**❌ 不可以做**：设家/传送（`/sethome` `/home` `/tpa` 无权限，迷路用 `/back` 或求助）；圈地；开玩家商店；使用 WorldEdit / 创造模式 / 飞行。
**升级路径**：在线累计 **10 小时自动晋升成员**（挂机/游玩均可累积），无需申请。

#### 🔵 成员（L1）— 完整玩家功能

**职责**：圈地建家、开店经营、参与服务器经济生态。

**可用指令集**：

| 分类 | 指令 | 功能 |
|:--|:--|:--|
| 家 | `/sethome` `/home` `/listhomes` `/delhome` | 设家 / 回家 / 列表 / 删除 |
| 传送 | `/tpa 玩家` `/tpahere 玩家` `/tpaccept` `/tpdeny` `/tpacancel` | 传送请求全套 |
| 公共点 | `/warp` | 查看 / 传送公共传送点 |
| 圈地 | `/claim 名字`（木锄选点）`/abandonclaim` | 圈地 / 放弃单个领地 |
| 领地 | `/trapped` `/ignore` | 卡死自救 / 无视玩家 |
| 邮件 | `/mail` `/mail send 玩家 内容` | 留言 / 收信 |
| 补给 | `/kit` | 领取补给包 |
| 个人 | `/ptime day` `/pweather clear` | 个人时间 / 天气（只影响自己） |
| 商店 | 箱子 + 告示牌创建玩家商店 | 开店卖货 |

**✅ 可以做**：设家、互相传送、用公共传送点；**圈地保护建筑**（木锄选两个对角点 → `/claim 名字`）；**开玩家商店**参与自由交易；离线留言、领补给包。
**❌ 不可以做**：创造模式 / 飞行 / WorldEdit（需升建造者）；修改他人领地；未经同意在他人领地内破坏/放置方块（有保护会被拒）。
**升级路径**：有建设成果（建筑/作品）→ 群里联系管理员 **申请晋升建造者**。

#### 🟡 建造者（L2）— 建设主力军

**职责**：服务器建设主力——大型建筑、公共设施、道路传送点，用作品美化世界。

**可用指令集**：

| 分类 | 指令 | 功能 |
|:--|:--|:--|
| 模式 | `/gamemode creative` `/gamemode survival` / **F3+F4 热键** | 切换创造 / 生存 |
| 飞行 | `/fly` `/speed 数字` | 飞行 / 速度 |
| 选区 | `//wand` `//pos1` `//pos2` `//expand 数量` | 木斧选区 / 扩展 |
| 编辑 | `//set 方块` `//replace` `//fill` | 填充 / 替换 |
| 剪贴板 | `//copy` `//paste` | 复制粘贴 |
| 历史 | `//undo` `//redo` | 撤销 / 重做 |
| 原理图 | `//schem save 名字` `//schem load 名字` `//schem paste` | 保存 / 加载 / 粘贴 |
| 笔刷工具 | `//brush 类型 方块` `//tool 类型` | 笔刷 / 工具 |
| 区域 | `/rg claim 名字` `/rg define` `/rg remove` `/rg addmember 区域 玩家` `/rg removemember` `/rg flag 区域 标志 值` `/rg list` `/rg info` `/rg tp` | WorldGuard 区域管理全套 |
| 便利 | `/heal` `/workbench` `/top` | 回血 / 随身工作台 / 回地表 |
| 投影 | `/setblock` `/fill` `/data`（Litematica 用）| 原版命令模式粘贴 |

**✅ 可以做**：创造模式 + 飞行 + WE 快速建造大型建筑；精细管理区域权限（谁能进、谁能改，`/rg flag`）；Litematica 投影粘贴大图（保持客户端默认设置、大图分块）；帮新人建造、维护公共设施。
**❌ 不可以做**：修改**他人**的游戏模式（`/gamemode creative 别人` 被拒）；调大编辑上限（`//limit` 无权限——100 万方块/次为硬上限防卡服）；批量填充物理方块（沙/沙砾/水/岩浆被 WorldEdit 禁用防级联卡服）；任何管理命令；召唤实体（Litematica 请开启 `pasteIgnoreEntities` 跳过）。
**升级路径**：管理员邀请/任命（长期活跃 + 贡献突出）。

#### 🔴 管理员（L3）— 维护服务器秩序

**职责**：维护秩序（踢人/封禁/禁言）、服务玩家（帮助/给予/传送）、服务器日常维护。

**可用指令集**：

| 分类 | 指令 | 功能 |
|:--|:--|:--|
| 踢封 | `/kick 玩家` `/ban 玩家` `/tempban 玩家 时长` `/banip IP` `/unban 玩家` `/unbanip IP` | 玩家 / IP 封禁管理 |
| 禁言 | `/mute 玩家` `/unmute 玩家` | 禁言 / 解禁 |
| 白名单 | `/whitelist list` `/whitelist add 玩家` `/whitelist remove 玩家` | 白名单管理 |
| 给予 | `/give 玩家 物品 数量` `/gamemode creative 玩家` | 发物品 / 改模式 |
| 传送 | `/tp 玩家` `/tp 玩家A 玩家B` | 传送玩家 |
| 状态 | `/effect 玩家 clear` `/save-all` | 清效果 / 存档 |
| 世界 | `/time set day` `/weather clear` | 时间 / 天气 |
| 领地 | `/gpadmin` `/restorenature` | 领地管理 / 自然恢复 |
| 区域 | `/rg`（bypass/override）| 覆盖区域限制 |
| 插件 | `/config`（OrzMC 配置）`/portal`（传送门）| 管理操作 |

**✅ 可以做**：维护秩序（警告 → 禁言 → 踢出 → 封禁梯度处理）；帮助玩家（给予、传送、清效果、重置密码）；服务器日常（存档、时间天气、白名单）；与群机器人配合（`$` 系列命令）。
**❌ 不可以做（红线）**：**不可给自己/他人 `op`**（管理走逐项权限）；**不可直接操作 LuckPerms**（权限变更走 OrzMC `$p` 或管理群/面板）；**不可执行 `/stop` `/reload`**（服务器重启/重载请通过管理面板或 RCON 操作）；不可滥用给予/封禁（所有操作可追溯，群里有操作通知）。
**升级路径**：管理员邀请/任命（长期活跃 + 信任积累）。

### 成长建议

1. **从访客做起**：先进服体验，找到自己感兴趣的方向（建筑/红石/农场/贸易）
2. **10 小时自动升成员**：多玩多聊，成员后就能**圈地建家、开店赚钱**
3. **想当建造者**：在群里发你的建筑作品 → 管理员看到成果后邀请你升级
4. **共建生态**：圈好地 → 建特色建筑 → 开商店 → 邀请朋友来玩，共同繁荣

## 如何自定义皮肤

登录图片保存网站 [imgur](https://imgur.com/)，上传你的皮肤后获取下载链接，在游戏里使用命令进行设置：

```bash
/skinsrestorer:skin set <your_skin_image_download_link>
```

## 新人避坑指南

| ⚠️ 事项 | 说明 |
|:--|:--|
| 尊重他人建筑 | 未经允许**不要拆/改别人的建筑和领地**，违者可能被管理员处理 |
| 不要刷屏 | 连续快速发消息可能被系统自动踢出（防刷机制） |
| 密码保护 | 注册密码**不要告诉任何人**，防止账号被盗 |
| 死亡掉落 | 死亡会掉落物品（有死亡箱保护），贵重物品建议放箱子里 |
| TNT 保护 | 服务器已开启 TNT 防护，**禁止用 TNT 破坏地形/建筑** |
| 传送弓冷却 | `/tpbow` 传送有 3 秒冷却，连射不会连续传送 |
| 经济防刷 | 可再生/自动化商品商店**禁卖**（提示 `That item cannot be sold`）——刷钱行为会被管理员处理 |
