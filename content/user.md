## 欢迎加入 OrzMC

这里是一个由玩家共同建设的 Minecraft 社区。服务器中一些热爱创造的小伙伴花费了大量心力建造出各种漂亮的建筑，希望刚加入的朋友不要随意破坏，**尊重他人的劳动成果**。

如果是完全小白，进服后感觉没有玩伴或者不太熟悉环境，欢迎加入**玩家群**——群里有很多资深玩家可以带你。玩家群入口在下方服务器卡片上，点击即可加入。

---

## 快速进服（3 步）

### 第 1 步：申请白名单

服务器采用**强制白名单**（未在白名单内的玩家无法进入）。请在下方**服务器卡片上点击「玩家群」加入**，向管理员提交你的游戏用户名，审核通过后即可进服。

### 第 2 步：连接服务器

服务器实时状态与地址（点击卡片可查看地址、加入玩家群）：

{{< server-status tags="cn" >}}

1. 启动游戏 → 多人游戏 → 添加服务器，填入上方卡片中的地址
2. 首次进入会要求**注册密码**（防止账号被盗用），在聊天框输入：

```
/register 你的密码 重复密码   ← 首次注册
/login 你的密码               ← 之后每次进入登录
```

3. 登录成功即可开始游戏！

> 💡 **/help LoginSecurity** 可查看登录插件的所有可用指令。

### 第 3 步：开始游戏

进服后输入 `/guide` 查看新手书，输入 `/menu` 打开服务器菜单。下面从常用指令开始认识这个世界～

## 常用指令速查

### 💬 聊天交流

| 操作 | 指令 | 说明 |
|:--|:--|:--|
| 公屏聊天 | 直接按 `T` 输入 | 所有在线玩家可见 |
| 私聊 | `/msg 玩家名 内容` | 只发给对方 |
| 回复 | `/r 内容` | 快速回复上一位私聊你的人 |
| 挂机 | `/afk` | 标记暂时离开（不占用资源） |
| 留言 | `/mail send 玩家名 内容` | 给离线玩家留言，上线即可收到 |

### 💰 经济交易

| 指令 | 功能 |
|:--|:--|
| `/balance` | 查看钱包余额 |
| `/baltop` | 查看全服财富排行 |
| `/pay 玩家名 金额` | 给其他玩家转账 |
| `/shop` | 打开系统商店（买/卖基础物资） |
| `/playershops` | 浏览所有玩家开的商店 |

### 🏠 生存传送

| 指令 | 功能 |
|:--|:--|
| `/sethome` | 在当前站立点设家 |
| `/home` | 传送到家 |
| `/listhomes` | 查看所有的家 |
| `/delhome <home_name>` | 删除设置的家 |
| `/tpa 玩家名` | 请求传送到对方身边 |
| `/tpahere 玩家名` | 邀请对方传送到你身边 |
| `/warp` | 查看/传送到公共传送点 |
| `/back` | 死亡后回到死亡点 |
| `/trapped` | 卡在方块里时自救传送 |
| `/tpbow` | 领取传送弓（射箭命中即传送） |

> **/help getmehome** 可查看家插件的所有可用指令。

### ⚰️ 死亡找回

出门探险获得不少物品，可能不小心被苦力怕炸飞，或被小白洞穿。复活后使用 **/back** 可快速回到死亡地点，找回收纳掉落物品的箱子：

- 箱子**五分钟内有效**，超时掉落物品会消失
- 若死于岩浆，箱子会被融化，物品无法找回 **#-_-#**

## 沟通与协作（一起建设生态）

### 游戏内协作

- **互相帮助**：新人缺资源 → 私聊老玩家 `/msg`，或去公共商店买
- **留言联系**：对方不在线 → `/mail send 玩家名 内容`，上线即可收到
- **共同建设**：在群里约好位置 → 一起搭建筑、修路、建传送点

### 群聊机器人（玩家群内直接发送）

| 指令 | 功能 |
|:--|:--|
| `$l` | 查看当前在线玩家 |
| `$w` | 查看白名单列表 |
| `$h` | 查看全部群指令帮助 |
| `$x ?` | 查看单个指令用法示例 |

> 群里还能收到玩家上下线通知，随时知道谁在服里，方便约着一起玩。

### 🏰 保护自己的建筑

| 功能 | 方式 | 等级要求 |
|:--|:--|:--|
| **圈地（GriefPrevention）** | 手持**木锄**左键/右键选两个对角点 → 输入 `/claim 领地名字` | 成员 |
| **区域保护（WorldGuard）** | `//wand` 选区域 → `/rg claim 名字` | 建造者 |
| **玩家商店** | 摆放箱子+告示牌，按提示创建 | 成员 |

> 💡 圈地后你的建筑只有你（和受邀成员）能修改，不怕被熊。**进别人的领地前先打声招呼**，尊重劳动成果。

### 📈 经济生态

> 服务器有经济系统：挖矿、种田、打怪获得资源 → 卖给商店换钱 → 买自己缺的东西。**玩家间自由交易**是生态的重要一环！

## 四级权限成长路径

服务器采用 **访客 → 成员 → 建造者 → 管理员** 四级体系，权限逐级递增，越往上代表你越受信任、能为服务器做的贡献越大。

| 等级 | 身份 | 在线要求 | 核心能力 | 怎么升级 |
|:--|:--|:--|:--|:--|
| 🟢 **L0 访客** | 新朋友 | 进服即有 | 聊天、私聊、看余额、转账、逛商店、回死亡点、领补给 | —— |
| 🔵 **L1 成员** | 活跃玩家 | 在线累计 **10 小时** | 设家/传送、tpa、公共传送点、**圈地保护**、**开玩家商店**、邮件 | **自动晋升**（挂机/游玩均可累积） |
| 🟡 **L2 建造者** | 建设主力 | 表现活跃 | **创造模式**、**飞行**、WorldEdit 快速建造、区域保护、随身工作台 | 向管理员申请（有建设成果/作品更佳） |
| 🔴 **L3 管理员** | 管理团队 | 长期活跃+信任 | 踢人/封禁、白名单管理、传送玩家、发放物品、时间天气、服务器维护 | 管理员邀请/任命 |

### 各等级能力明细

**🟢 访客（L0）— 生存基础体验**
- 完整生存玩法：挖矿、种田、打怪、合成
- 聊天交流：公屏、私聊、挂机
- 经济：查看余额、转账、逛系统商店和玩家商店

**🔵 成员（L1）— 完整玩家功能**
- 解锁全部传送能力：家、tpa、warp、死亡回点
- **圈地保护**：用木锄圈下自己的领地，建筑不怕被破坏
- **开玩家商店**：摆摊卖货，参与服务器经济
- 邮件留言、领取补给包

**🟡 建造者（L2）— 建设主力军**
- **创造模式 + 飞行**：快速搭建大型建筑
- **WorldEdit 创世神**：选区填充、复制粘贴、批量建造、撤销
- **区域保护**：用 WorldGuard 精细管理区域权限（谁能进、谁能改）
- 随身工作台、快速回地表

**🔴 管理员（L3）— 维护服务器秩序**
- 玩家管理：踢人、封禁、解封
- 白名单管理：添加/移除新玩家
- 服务器管理：传送玩家、发放物品、设置时间天气、存档

### 成长建议

1. **从访客做起**：先进服体验，找到自己感兴趣的方向（建筑/红石/农场/贸易）
2. **10 小时自动升成员**：多玩多聊，成员后就能**圈地建家、开店赚钱**
3. **想当建造者**：在群里发你的建筑作品 → 管理员看到成果后邀请你升级
4. **共建生态**：圈好地 → 建特色建筑 → 开商店 → 邀请朋友来玩，共同繁荣

## 如何自定义皮肤

登录图片保存网站 [imgur](https://imgur.com/)，上传你的皮肤后获取下载链接，在游戏里使用命令进行设置：

```bash
/skinsrestorer:skin set <your_skin_image_download_link>
```

## 新人避坑指南

| ⚠️ 事项 | 说明 |
|:--|:--|
| 尊重他人建筑 | 未经允许**不要拆/改别人的建筑和领地**，违者可能被管理员处理 |
| 不要刷屏 | 连续快速发消息可能被系统自动踢出（防刷机制） |
| 密码保护 | 注册密码**不要告诉任何人**，防止账号被盗 |
| 死亡掉落 | 死亡会掉落物品（有死亡箱保护），贵重物品建议放箱子里 |
| TNT 保护 | 服务器已开启 TNT 防护，**禁止用 TNT 破坏地形/建筑** |
| 传送弓冷却 | `/tpbow` 传送有 3 秒冷却，连射不会连续传送 |

## 遇到问题怎么办？

| 问题 | 解决方式 |
|:--|:--|
| 忘记密码 | 找管理员重置 |
| 卡在方块里 | `/trapped` 自救 |
| 迷路了 | `/home` 回家，或 `/warp` 去公共点 |
| 物品丢失 | 联系管理员协助（有备份机制） |
| 其他问题 | 群里发 `$h` 看帮助，或直接 @管理员 |
